# Brand assets

Exported from the Wix site at mabc.org.nz. The lockup's two colours, sampled
from the artwork: mark `#56c4e8`, wordmark `#6f5047`.

| File | Use |
|---|---|
| `mark.png` | The masthead, the footer and the favicon |
| `apple-touch-icon.png` | The mark composited over white, since iOS backs a transparent icon with black |
| `lockup.png` | Not used on the site. Kept because it is the church's artwork |
| `lockup-dark.png` | Not used on the site. The wordmark recoloured white, for a dark ground |

The site shows the mark and sets "Mt Albert Baptist" in Red Hat Display rather
than using the lockup. The lockup's wordmark is a warm brown that is the only
brown anywhere on the site and sits badly beside the interface's blue, and its
mark fills 96% of the lockup's height while the wordmark fills 58%, so at any
height that fits the masthead the name renders smaller than the navigation
beside it.

These are raster files scaled from the Wix export. If the original vector
artwork can be found, replace them with it.
